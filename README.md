# Rusidian

**Obsidian vault를 그대로 여는 가벼운 Windows 노트 앱.** 노트·할일·캘린더·가계부·그래프를 한 앱에서 씁니다.
모든 내용은 vault 안의 마크다운 파일에 있어서, 같은 vault를 Obsidian과 번갈아 열어도 됩니다.

**[⬇ 최신 버전 내려받기](https://github.com/LiU-SKY/rusidian/releases/latest)** · Windows 10/11 (64비트)

## 주요 기능

- **노트** — CodeMirror 편집기, 라이브 미리보기·읽기 보기, `[[링크]]`·백링크·임베드, 속성(frontmatter) 편집, 수식(KaTeX)·Mermaid·각주, 캔버스(`.canvas`), PDF로 내보내기
- **찾기** — 빠른 전환(Ctrl+O), 명령 팔레트(Ctrl+P), 한국어에 맞는 부분 문자열 검색, 북마크, 태그·개요 패널, 그래프 보기
- **할일·일정** — Obsidian Tasks 플러그인 형식(마감·반복·우선순위), 월·주·일 캘린더, 데일리 노트, Windows 알림, Google·Outlook 캘린더 구독(읽기 전용)
- **재무** — 노트에 `- 💸 12,000 점심 #식비`처럼 적으면 가계부로 집계. 예산, 고정지출, 계좌 잔액(자산), 은행·카드·페이 거래 내역(CSV·엑셀·농협 PDF) 가져오기
- **안전한 저장** — 자동 저장, 바깥에서 바뀐 노트는 덮어쓰지 않고 사본으로, 노트 이전 버전 복구, 휴지통 삭제
- **Git 동기화** — 고른 폴더만 비공개 저장소에 올려 여러 기기에서 같은 vault 쓰기
- **Obsidian 설정 공유** — 템플릿·데일리 노트·단축키·북마크·그래프 색 설정을 Obsidian과 같은 `.obsidian/` 파일로 읽고 씀

## 설치

1. [릴리스 페이지](https://github.com/LiU-SKY/rusidian/releases/latest)의 **Assets**에서 `Rusidian_<버전>_x64-setup.exe`를 내려받아 실행합니다.
   관리자 권한 없이 지금 사용자에게 설치됩니다(한국어 설치 화면).
   - 회사 PC처럼 MSI가 필요하면 `Rusidian_<버전>_x64_ko-KR.msi`를 씁니다.
   - `.sig` 파일과 `latest.json`은 자동 업데이트용이라 내려받지 않아도 됩니다.
2. 설치 파일에 코드 서명을 하지 않아서 Windows가 **"Windows의 PC 보호"**(알 수 없는 게시자) 창을 띄울 수 있습니다.
   **추가 정보 → 실행**을 누르면 설치됩니다.
3. 앱을 열고 **Vault 폴더 열기**로 Obsidian vault(또는 마크다운 파일을 둘 아무 폴더)를 고릅니다.

WebView2가 없는 PC(오래된 Windows 10)에서는 설치 프로그램이 WebView2를 내려받아 함께 설치합니다.

## 업데이트

새 버전이 나오면 앱을 켤 때 알려 줍니다. **설치하고 다시 시작**을 누르면 열린 노트를 모두 저장한 뒤
새 버전을 설치하고 다시 엽니다. 설정 → 일반 → **업데이트 확인**으로 직접 확인할 수도 있습니다.
설치 파일은 서명을 확인한 뒤에만 설치하므로, 이 저장소의 릴리스가 아닌 파일로 바뀌지 않습니다.

## 데이터와 개인정보

- **노트와 기록은 vault 폴더에만 있습니다.** 가계부·할일·잔액도 노트 안의 평범한 마크다운 줄이라, 앱을 지워도 그대로 남습니다.
- vault에 딸린 설정(예산, 고정지출, 동기화할 폴더 등)은 vault의 `.obsidian/` 안에,
  이 기기의 설정(테마·탭 구성·알림 기록·노트 이전 버전)은 `%APPDATA%\com.rusidian.app`, `%LOCALAPPDATA%\com.rusidian.app`에 저장됩니다.
- 앱이 인터넷에 연결하는 경우는 세 가지뿐입니다.
  - **업데이트 확인:** 켤 때 이 저장소의 GitHub 릴리스에서 새 버전 정보를 받습니다.
  - **외부 캘린더 구독:** 직접 넣은 캘린더 주소에서 일정을 받습니다.
  - **Git 동기화:** 켰을 때만, 직접 정한 저장소와 주고받습니다.
- 암호 걸린 거래 내역 파일의 비밀번호는 파일을 여는 데만 쓰고 저장하지 않습니다.

## 사용법

| 동작 | 방법 |
|------|------|
| 링크 따라가기 | `[[노트]]`를 **Ctrl+클릭** (없는 노트면 vault 루트에 새로 만듦). `[[노트#제목]]`·`[[#제목]]`은 그 제목으로 이동 |
| 북마크 | 노트 위 **북마크** 버튼(또는 명령 팔레트 "현재 노트 북마크 추가/빼기") — 사이드바 **북마크** 탭에 그룹·파일·제목·검색 북마크. 누르면 열기(검색은 검색 탭에서 실행, 폴더는 파일 트리에서 보기), ×로 빼기. Obsidian과 같은 `.obsidian/bookmarks.json`을 써서 서로 공유되고, 모르는 항목(그래프 등)도 그대로 둠. 파일 이름을 바꾸거나 옮기면 북마크도 따라감 |
| 나가는 링크 | 오른쪽 패널 **나가는 링크** — 이 노트의 링크를 대상별로(여러 번이면 횟수), 아직 없는 노트는 따로. 없는 노트를 누르면 만들어 열기 |
| 링크 없는 언급 | 백링크 패널 아래 **링크 없는 언급**(펼칠 때 찾음) — 이 노트의 이름이나 `aliases`를 링크 없이 쓴 줄(링크·코드·URL 안은 제외). **링크** 버튼으로 그 자리를 `[[노트]]`(다른 글자면 `[[노트\|글자]]`)로 바꿈 |
| 글자 수 | 노트 아래 상태 줄에 단어·글자(공백 포함)·공백 제외 글자 수. 속성(frontmatter)은 빼고 셈. 편집기에서 글자를 선택하면 선택한 부분만 |
| 읽기 보기 | 노트 상단 📖 버튼 또는 **Ctrl+E** — 마크다운을 렌더링해서 보기. `[[링크]]`·태그 클릭, 할일 체크, 콜아웃(`> [!note]`), `==강조==`, `%%주석%%` 숨김, 표 |
| 라이브 미리보기 | 편집 중 커서가 없는 줄은 `**`·`#`·링크 주소 같은 기호를 숨기고 체크박스·글머리·이미지를 그려서 보여줌. 설정에서 끄면 소스 모드 |
| 임베드 | `![[이미지.png\|300]]`, `![[노트]]`, `![[노트#제목]]`, `![[노트#^블록]]`, PDF·오디오·동영상. 이미지·PDF 파일은 열면 바로 보임 |
| 수식 | `$E = mc^2$`(인라인), `$$ … $$`(블록) — KaTeX로 그림. 읽기 보기와 라이브 미리보기(커서가 없는 줄·블록) 모두. `$5 and $10`처럼 `$` 뒤나 닫는 `$` 앞에 공백이 있으면 수식이 아님. 처음 쓸 때만 불러옴 |
| PDF로 내보내기 / 인쇄 | 명령 팔레트 **PDF로 내보내기 / 인쇄** 또는 **Ctrl+Shift+P** — 지금 노트를 읽기 보기처럼 그려 인쇄 창을 엶. 프린터 대신 **PDF로 저장**을 고르면 PDF 파일(이름은 노트 이름). 다크 테마에서도 밝은 색으로, 맨 위에 노트 이름(본문이 같은 `# 제목`으로 시작하면 생략), 속성(frontmatter)은 빼고, 수식·Mermaid·이미지·노트 임베드가 다 그려진 뒤 인쇄. 제목 바로 뒤나 표·코드·그림 가운데서 페이지가 나뉘지 않게 함. 용지·여백·머리글은 인쇄 창에서 고름 |
| 캔버스 | Obsidian 캔버스(`.canvas`, JSON Canvas)를 열고 편집. 텍스트 카드(마크다운으로 보임, `[[링크]]` 클릭), 노트 카드(노트 내용 미리보기, 두 번 클릭하면 열기), 이미지·파일·웹 링크 카드, 그룹, 화살표(라벨·양끝 화살표). **만들기:** 빈 곳 두 번 클릭(텍스트 카드), 아래 도구 막대(텍스트·노트/파일·그룹), 파일 트리에서 노트를 끌어다 놓기, 카드 가장자리 점을 끌어 다른 카드에 놓으면 화살표(빈 곳에 놓으면 새 카드와 연결). **고치기:** 끌어서 옮기기(그룹은 안의 카드와 함께), 오른쪽 아래 점으로 크기, 두 번 클릭(또는 Enter)으로 글·그룹 이름·화살표 라벨 고치기, Obsidian의 6가지 색, Delete로 삭제, Shift+클릭 여러 개 고르기, Ctrl+A 전체. **보기:** 스크롤로 이동(Shift: 가로), Ctrl+스크롤로 부드럽게 확대·축소, 빈 곳 끌어서 이동, 화면에 맞추기. Obsidian처럼 탭 들여쓰기 JSON으로 저장하고 모르는 항목은 그대로 둠. 새 캔버스는 명령 팔레트 **새 캔버스** 또는 폴더 오른쪽 클릭 |
| 다이어그램 | ` ```mermaid ` 코드 블록을 Mermaid 다이어그램으로 (테마 색 따라감, 문법 오류는 메시지와 원문 표시). 처음 쓸 때만 불러옴 |
| 각주 | `문장[^1]` + `[^1]: 설명`, 또는 인라인 `^[설명]` — 읽기 보기에서 번호(참조 순서)와 맨 아래 각주 목록, 번호↔목록 이동 |
| 이미지 붙여넣기 | 캡처한 이미지를 노트에 **Ctrl+V** → `Pasted image 20261114153012.png`로 저장하고 커서 자리에 `![[…]]` 삽입. 탐색기에서 파일을 편집기로 **끌어다 놓아도** 원래 이름으로 저장(이름이 겹치면 `이름 1.png`). 저장 위치·링크 형식은 Obsidian 설정(`.obsidian/app.json`의 첨부 파일 폴더, 마크다운 링크 사용, 새 링크 형식)을 따름. 클립보드에 글자도 있으면(엑셀 셀 복사 등) 글자를 붙여 넣음. 50MB까지 |
| 속성 편집 | 노트 위 속성 패널에서 바로 수정 — 텍스트, 숫자, 체크박스, 날짜, 목록(태그 칩 추가/삭제), 이름 바꾸기, 삭제, **속성 추가** (명령 팔레트에도 있음) |
| vault 창 | **Ctrl+Shift+N** 새 창, vault 전환 목록에서 **Ctrl+Enter**로 그 vault를 새 창에서 열기. 창마다 vault가 따로 열리고(Obsidian처럼), 이미 다른 창에 열린 vault를 고르면 그 창을 앞으로 가져옴. 창 제목에 vault 이름. 테마·글자 크기 같은 설정은 모든 창에 함께 적용. 앱을 다시 켜면 첫 창이 마지막 vault를 엶 |
| Git 동기화 | 사이드바 아래 **동기화** 버튼(오른쪽 클릭: 설정) 또는 명령 팔레트 "Git 동기화 설정" — 비공개 저장소 주소를 넣고 올릴 폴더를 고름. 설정(`.obsidian` 폴더 전체: 플러그인·테마·CSS 스니펫·단축키, Rusidian 설정)은 항상, 노트 폴더는 고른 것만. 앱을 열 때·정해 둔 간격마다·버튼을 누를 때 동기화. 자세한 내용은 아래 [Git 동기화](#git-동기화) |
| vault 전환 | 사이드바 맨 위 vault 이름 클릭 또는 **Ctrl+Shift+O** — 최근 vault 목록에서 골라 열기, "다른 폴더를 vault로 열기". 없어진 폴더는 "폴더 없음"으로 표시, ×로 목록에서 빼기(폴더는 그대로). vault마다 탭·최근 파일을 따로 기억. vault가 열려 있지 않으면 시작 화면에 최근 목록 |
| 탭 | 노트·캘린더·할일 등이 탭으로 열림. **Ctrl+클릭**(파일 트리·검색)이나 휠 클릭은 새 탭, **Ctrl+T** 새 탭, **Ctrl+W** 닫기, **Ctrl+Tab** 다음 탭. 열어 둔 탭은 vault별로 기억 |
| 분할 | 탭 줄 오른쪽 분할 버튼 또는 **Ctrl+\\** — 두 창 나란히. 같은 노트를 양쪽에 열면 입력이 바로 맞춰짐 |
| 템플릿 | **Alt+T** 또는 명령 팔레트 "템플릿 삽입" — `.obsidian/templates.json`의 폴더에서 골라 커서 위치에 넣음. `{{title}}` `{{date}}` `{{time}}` `{{date:YYYY년 M월 D일 dddd}}`, 템플릿의 속성은 노트 속성에 합침 |
| 빠른 전환 | **Ctrl+O** — 파일 이름 퍼지 검색, 빈 입력이면 최근 연 파일 순. Enter 열기, **Shift+Enter** 그 이름으로 새 노트 |
| 명령 팔레트 | **Ctrl+P** — 모든 기능을 이름으로 찾아 실행 (보기 전환, 현재 파일 이름 바꾸기/삭제, 테마 전환 등) |
| 검색 | **Ctrl+Shift+F** — 부분 문자열, 여러 단어는 AND, `"구문"` 지원, Enter로 첫 결과 열기 |
| 검색 연산자 | `tag:#일` (하위 태그 포함), `path:폴더`, `file:이름`, `-단어` (제외). 섞어 쓸 수 있음 |
| 오른쪽 패널 | 노트 상단 패널 버튼으로 토글 (창 너비 900px 미만에선 숨김). 탭: **백링크** · **개요**(제목 목록, 클릭하면 이동) · **태그**(vault 전체, 클릭하면 태그 검색) |
| 설정 | 사이드바 아래 버튼 또는 **Ctrl+,** — 테마(시스템/라이트/다크), 편집기 글자 크기, 읽기 좋은 줄 너비, 지금 버전과 **업데이트 확인** |

| 그래프 색 그룹 | 그래프 화면 **색 그룹** — `path:폴더`, `tag:#태그`, `file:이름`, `-제외` 조건마다 색. 위 그룹이 먼저, 왼쪽 아래 범례. Obsidian과 같은 `.obsidian/graph.json`의 colorGroups를 읽고 씀 |

그래프는 이름 검색 강조, 고립된 노트 / 없는 노트(미해결 링크) / 첨부 파일 표시 여부를 고를 수 있습니다.
노트 800개 또는 링크 1,500개가 넘으면 배치를 화면 밖에서 먼저 계산(진행률 표시)한 뒤 그리고,
그린 장면을 캐시해 두어 이동·확대·마우스 오버가 매끄럽습니다(노트 3,000개·링크 6,000개에서 배치 약 1.8초, 이동 중 60fps 이상).

### 재무 기록 형식

노트 어디에나 목록 항목으로 씁니다. Obsidian에서도 그대로 읽히는 평범한 마크다운입니다.

```markdown
- 💸 12,000 점심 김밥 #식비                    ← 지출
- 💰 3,000,000원 월급 #급여                    ← 수입
- 💸 ₩45,000 택시 #교통/택시 📅 2026-11-10     ← 날짜 지정
- 💸 -23,000 무신사 환불 #옷                   ← 환불·돌려받은 돈 (그 분류 지출에서 뺌)
- 💰 -300,800 연구실 비용 #인건비              ← 차감 (그 분류 수입에서 뺌)
- 🏦 2,700,000 NH청년도약계좌 #저축 📅 2026-11-14 ← 계좌 잔액 (자산 탭)
- 💸 30,600 맘스터치 #식비 📅 2026-10-28
    - 💸 -10,100 김민준 정산                   ← 들여쓴 줄 = 위 결제의 정산·환불
    - 💸 -10,100 박서준 정산 📅 2026-10-29     ← 날짜가 다르면 📅
```

- 이모지(`💸` 지출 / `💰` 수입) 바로 뒤에 금액. 쉼표·`원`·`₩`·소수점 둘째 자리까지 허용. 금액 앞에 `-`(또는 `−`)를 붙이면 환불·차감으로, 같은 종류·분류의 합계에서 빠집니다.
- 첫 번째 `#태그`가 분류(`#교통/택시`처럼 계층 가능), 나머지 글자가 내용. 분류가 없으면 "미분류".
- 날짜 결정 순서: 줄의 `📅` → 데일리 노트 경로의 날짜 → 노트 속성 `date:` → 파일 이름 앞의 `YYYY-MM-DD`.
  아무것도 없으면 합계에서 빼고 "날짜를 알 수 없는 기록"으로 따로 보여줍니다.
- 기록 아래에 들여쓴 기록은 그 기록의 정산·환불입니다. 분류·날짜를 따로 적지 않으면 위 기록의 것을 씁니다.
  합계에는 각자 자기 날짜로 들어가고, 거래 내역의 "합쳐 보기"와 상세에서 결제와 함께 보입니다.
- 코드 블록 안의 줄은 무시합니다. 수정·삭제는 기록이 있는 노트에서 직접 합니다(거래 내역의 노트 이름 클릭).

### 할일 (Obsidian Tasks 플러그인 호환)

이모지 형식을 그대로 읽고 씁니다: `📅` 마감, `⏳` 예정, `🛫` 시작, `➕` 생성, `✅` 완료, `❌` 취소,
`🔁` 반복, `🔺⏫🔼🔽⏬` 우선순위, `#태그`. 상태는 `[ ]` 할일, `[/]` 진행 중, `[x]` 완료, `[-]` 취소.

- 완료 처리 시 화면에 보이던 줄과 파일의 줄이 다르면(그사이 바깥에서 수정) 아무것도 고치지 않고 거부합니다.
- 반복 규칙: `every [N|other] day|week|month|year[s]`, `every weekday`/`weekend`, `every monday, wednesday and friday`,
  `every [N] week[s] on tuesday`, `every [N] month[s] on the 15th`/`the last day`/`the 2nd tuesday`/`the last friday`,
  `every [N] year[s] on january 5th`, 그리고 각각 뒤에 `when done`. 마감(없으면 예정·시작)일 기준으로 다음 날짜를
  계산하고 다른 날짜도 같은 만큼 옮깁니다. 월말은 말일로 맞춥니다(1/31 → 2/28). 읽을 수 없는 규칙은 잘못 고치는 대신 완료를 거부합니다.
- Dataview 형식(`[due:: 2026-11-20]`, `[completion:: …]`)도 읽고, 그 형식으로 쓰인 할일은 같은 형식으로 고칩니다.

데일리 노트 위치는 `.obsidian/daily-notes.json`의 폴더·형식·템플릿 설정을 따릅니다. 날짜 형식은
Obsidian(moment.js)과 같은 규칙에 한국어 이름입니다: `YYYY YY M MM`, `MMMM`(11월), `D DD Do`(13일),
`DDD DDDD`(그해 며칠째), `dddd`(금요일) `ddd`(금), `d e E`(요일 번호), `w ww wo gggg`(일요일 시작 주),
`W WW GGGG`(ISO 주), `Q`(분기), `L`·`ll` 같은 날짜 묶음, `[문자]`와 `\문자`(글자 그대로).
이름·요일·며칠째로 된 노트 이름도 날짜로 읽어 캘린더에 연결합니다(요일이 날짜와 맞지 않으면 데일리 노트로 보지 않음).
시간(`HH`, `A` 등)처럼 날짜만으로 채울 수 없는 기호가 있으면 추측하지 않고 오류를 냅니다. 대괄호 없이 쓴
영어 단어(예: `YYYY-MM-DD - Daily`)는 Obsidian에서도 글자마다 날짜·시간 기호로 바뀌므로, 어느 단어를
`[Daily]`처럼 감싸면 되는지 알려 줍니다. 템플릿의 `{{title}}`, `{{date}}`, `{{date:형식}}`, `{{time}}`을
같은 규칙으로 채웁니다.

Obsidian 등 바깥에서 파일을 바꾸면 자동으로 트리·검색·백링크에 반영되고, 열린 노트도 다시 읽습니다.
단, 아직 저장하지 않은 편집이 있으면 덮어쓰지 않고 내 편집을 저장합니다(나중 저장이 이김).

## Git 동기화

설치된 Git으로 vault를 비공개 저장소(GitHub, GitLab, 자체 서버 등)와 맞춥니다.
중요한 서류가 있는 vault도 쓸 수 있도록 **고른 것만** 올라갑니다.

- **항상 올라가는 것:** `.obsidian` 폴더(플러그인, 테마, CSS 스니펫, 단축키, Obsidian 설정)와
  Rusidian 설정(테마·글자 크기 등, `.obsidian/rusidian-app.json`).
  기기마다 다른 `workspace.json`(열린 탭 배치)은 빼고 올립니다.
- **고른 것만 올라가는 것:** 노트 폴더. 고르지 않은 폴더, vault 맨 위의 파일, 나중에 새로 만든
  폴더는 이 컴퓨터에만 남습니다. 대화상자에서 올라갈 파일 수·크기·목록을 미리 보여 줍니다.
- **선택:** 외부 캘린더 구독 주소(비공개 주소에는 토큰이 들어 있으므로 기본은 끔).
- 50MB가 넘는 파일은 올리지 않습니다(GitHub 한도).
- 폴더 선택은 `.obsidian/rusidian.json`에 저장되어 그 vault를 쓰는 모든 기기에 같이 적용됩니다.
  원격 주소·브랜치·자동 동기화 간격은 기기마다 따로입니다.
- Git 기록은 vault 밖(앱 데이터 폴더의 `sync/`)에 두므로 vault 안에 `.git`이 생기지 않습니다.
  vault에 이미 Git 저장소가 있어도 서로 건드리지 않습니다.
- 양쪽 기기에서 같은 파일을 고쳤으면 이 기기 내용을 그대로 두고, 다른 쪽 내용을
  `이름 (충돌 2026-11-14 0305).md`로 남깁니다. 동기화가 파일을 지우거나 덮어써서 잃는 일은 없습니다.
  폴더를 목록에서 빼도 각 기기의 파일은 그대로 남고, 올리지 않는 로컬 파일과 이름이 겹치는 파일이
  내려오면 로컬 파일을 `(충돌 … 이 기기)` 이름으로 옮겨 둡니다.
- **충돌 합치기:** 동기화 알림의 **비교해서 합치기** 또는 명령 팔레트 "동기화 충돌 합치기" — vault의 충돌 사본마다
  원래 파일과 줄 단위로 비교해 같은 부분은 접고, 다른 곳마다 **원래 파일 / 사본 / 둘 다**를 고름(어느 쪽이
  이 기기·다른 기기 것인지 표시). **결과 보기·고치기**에서 합친 내용을 직접 고칠 수도 있음. **합쳐서 저장**은
  원래 파일에 쓰고(이전 버전은 파일 복구에 남음) 사본을 휴지통으로, **사본 버리기**는 원래 파일을 그대로 둠.
  글자 파일이 아니거나 원래 파일이 없으면 **사본으로 바꾸기**. 줄바꿈 방식(CRLF)과 마지막 줄바꿈은 원래 파일대로.
  `.obsidian` 안 설정 파일의 충돌 사본은 목록에 나오지 않습니다(파일 탐색기에서 직접 확인).
- 로그인은 Git이 처리합니다(Windows는 Git Credential Manager 창). Git이 없으면 대화상자에 설치 링크가 나옵니다.
