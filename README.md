# Rusidian

가볍고 빠른 Rust 기반 노트 앱. 기존 **Obsidian vault를 그대로** 열고, Obsidian과 같은 vault를 번갈아 쓸 수 있도록 포맷을 호환합니다.

- 셸: Tauri 2 (Rust 백엔드 + OS WebView)
- 프론트엔드: SvelteKit (Svelte 5, SPA 모드)
- 원칙: **원본은 항상 vault 안의 마크다운 파일**. 인덱스/캐시는 부가물일 뿐.

## 실행

```bash
npm install
npm run tauri dev
```

> `tauri dev`가 돌아가는 중에 `npm run build`를 실행하면 `build/`가 바뀌면서 앱 창이 새로고침됩니다.

## 설치 파일 만들기 (릴리스 빌드)

```bash
npm run tauri build
```

`target/release/bundle/` 아래에 두 가지 설치 파일이 생깁니다.

| 파일 | 설명 |
|------|------|
| `nsis/Rusidian_<버전>_x64-setup.exe` | 권장. 관리자 권한 없이 현재 사용자에게 설치(한국어 설치 화면) |
| `msi/Rusidian_<버전>_x64_ko-KR.msi` | 회사 PC 배포처럼 MSI가 필요할 때 |

설치 없이 실행만 하려면 `target/release/rusidian.exe`. WebView2가 없는 PC(구형 Windows 10)에서는
설치 프로그램이 WebView2를 내려받아 설치합니다.

- 버전은 `src-tauri/tauri.conf.json`과 `src-tauri/Cargo.toml`, `package.json`의 `version`을 함께 올립니다
  (`Cargo.lock`, `package-lock.json`은 `cargo check`, `npm install`을 한 번 돌리면 따라 바뀝니다).
- 업데이트 파일에 서명하므로 로컬 빌드에도 서명 키가 필요합니다. 없으면 설치 파일까지 만든 뒤 서명 단계에서 멈춥니다.
  PowerShell: `$env:TAURI_SIGNING_PRIVATE_KEY = "$HOME\.tauri\rusidian-updater.key"; $env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = ""`
- 앱 아이콘은 `app-icon.svg`가 원본입니다. 고친 뒤 `npx tauri icon app-icon.svg`로 `src-tauri/icons`를 다시 만듭니다
  (데스크톱만 쓰므로 생성되는 `android/`, `ios/` 폴더는 지워도 됩니다).
- 설치 파일에 코드 서명은 하지 않았습니다. 처음 실행할 때 Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄울 수 있습니다.
- 설정·탭 구성·알림 기록은 사용자 폴더(`%APPDATA%\com.rusidian.app`, `%LOCALAPPDATA%\com.rusidian.app`)에 저장되고,
  vault 관련 설정(예산, 그래프 색 그룹 등)은 vault의 `.obsidian/` 안에 저장됩니다.

## 새 버전 내기 (자동 업데이트)

설치한 앱은 켤 때 GitHub 릴리스의 `latest.json`을 보고 새 버전을 알려 줍니다(**설치하고 다시 시작**,
또는 설정 → 일반 → **업데이트 확인**). 설치 전에 모든 창의 노트를 저장하고, 설치 파일의 서명이
`tauri.conf.json`의 `pubkey`와 맞을 때만 설치합니다.

1. 위 세 파일의 `version`을 올리고(예: `0.3.0`) 커밋합니다.
2. 같은 버전의 태그를 올립니다: `git tag v0.3.0`, `git push origin main v0.3.0`
3. GitHub Actions의 **Release**(`.github/workflows/release.yml`)가 설치 파일을 빌드·서명해 릴리스에 올립니다.
   태그와 `tauri.conf.json`의 버전이 다르면 멈춥니다.

서명 비밀키는 `%USERPROFILE%\.tauri\rusidian-updater.key`(비밀번호 없음)에 있고, 저장소 Secrets의
`TAURI_SIGNING_PRIVATE_KEY`에도 들어 있습니다. **이 키를 잃어버리면 이미 설치된 앱은 더 이상 업데이트를
받지 못하므로** 따로 백업해 둡니다.

## 사용법

| 동작 | 방법 |
|------|------|
| 링크 따라가기 | `[[노트]]`를 **Ctrl+클릭** (없는 노트면 vault 루트에 새로 만듦). `[[노트#제목]]`·`[[#제목]]`은 그 제목으로 이동 |

| 읽기 보기 | 노트 상단 📖 버튼 또는 **Ctrl+E** — 마크다운을 렌더링해서 보기. `[[링크]]`·태그 클릭, 할일 체크, 콜아웃(`> [!note]`), `==강조==`, `%%주석%%` 숨김, 표 |

Obsidian처럼 탭 들여쓰기 JSON으로 저장하고 모르는 항목은 그대로 둠. 새 캔버스는 명령 팔레트 **새 캔버스** 또는 폴더 오른쪽 클릭 |

| 분할 | 탭 줄 오른쪽 분할 버튼 또는 **Ctrl+\\** — 두 창 나란히. 같은 노트를 양쪽에 열면 입력이 바로 맞춰짐 |

| 명령 팔레트 | **Ctrl+P** — 모든 기능을 이름으로 찾아 실행 (보기 전환, 현재 파일 이름 바꾸기/삭제, 테마 전환 등) |

| 설정 | 사이드바 아래 버튼 또는 **Ctrl+,** — 테마(시스템/라이트/다크), 편집기 글자 크기, 읽기 좋은 줄 너비 |
| 템플릿·데일리 노트 설정 | 설정 → **템플릿·데일리 노트** 탭 — 템플릿 폴더·날짜 형식·시간 형식, 데일리 노트의 날짜 형식·새 파일 위치·템플릿 파일. 폴더와 노트는 목록에서 고를 수 있고, 입력하는 동안 `{{date}}`·`{{time}}` 결과와 오늘의 노트 경로를 미리 보여 줌. 날짜 형식의 글자가 기호로 읽히거나(`Daily` → `[Daily]`로) 폴더·템플릿 노트가 없으면 바로 알려 줌. 칸을 벗어나면 Obsidian과 같은 `.obsidian/templates.json`·`daily-notes.json`에 저장(모르는 키는 그대로) |
| 단축키 바꾸기 | 설정 → **단축키** 탭 — 명령 팔레트의 모든 명령에 키를 더하거나(+ 누르고 키 입력, Esc 취소) 지우거나 기본값으로 되돌림. 명령이나 키로 찾기, 두 명령에 같은 키면 빨갛게 표시. Ctrl·Alt 같은 키와 함께여야 함(F1~F12는 단독 가능). 한글 입력 상태에서도 같은 키로 동작(Ctrl+ㄷ = Ctrl+E). Obsidian의 `.obsidian/hotkeys.json`에 Obsidian과 같은 명령 이름·형식으로 저장 — Obsidian에서 바꾼 키가 여기서도, 여기서 바꾼 키가 Obsidian에서도 적용되고, 설정 폴더와 함께 Git 동기화로 다른 기기에 따라감. 모르는 명령의 키는 그대로 둠 |
| 저장 | 자동 저장(0.8초) 또는 **Ctrl+S**. 창을 닫을 때도 저장하고 닫음. 파일의 줄바꿈(CRLF/LF)은 그대로 둠. 편집하는 동안 다른 곳(동기화, Obsidian)에서 같은 노트가 바뀌었으면 덮어쓰지 않고, 바뀐 내용을 보여 주며 저장하지 않은 내용은 `이름 (충돌 … 이 기기).md` 사본으로 남김(**비교해서 합치기**) |
| 노트 제목·날짜 | 노트 맨 위에 파일 이름이 제목으로 보이고, 눌러서 바로 고칠 수 있음(Enter로 확정하고 본문으로, Esc로 취소). 이름을 바꾸면 이 노트를 가리키는 링크도 함께 고침. 그 아래 **만든 날**·**고친 날**(오늘·어제·날짜, 마우스를 올리면 초까지)이 저장할 때마다 새로 표시됨. 설정 → 노트 제목·날짜 보기로 끌 수 있음 |
| 새 노트 / 폴더 | 사이드바 위쪽 버튼, **Ctrl+N**, 또는 파일 트리 **오른쪽 클릭** — "제목 없음" / "새 폴더"로 만들고 바로 이름 입력 |
| 이름 바꾸기 | 오른쪽 클릭 → 이름 바꾸기, 또는 항목 선택 후 **F2**. Enter로 확정, Esc로 취소 |
| 옮기기 | 파일·폴더를 다른 폴더로 **끌어다 놓기** (빈 곳에 놓으면 vault 루트로). 닫힌 폴더 위에서 잠시 멈추면 열림 |
| 링크 자동 수정 | 이름을 바꾸거나 옮기면, 그 파일을 가리키던 `[[링크]]`·`[](링크)`를 새 위치로 고침 (별칭·`#제목`·`^블록`은 유지) |
| 삭제 | 오른쪽 클릭 → 삭제, 또는 **Delete** — 확인 후 **휴지통**으로 (영구 삭제 아님) |
| 탐색기에서 보기 | 오른쪽 클릭 → 탐색기에서 보기 |
| 파일 복구 (이전 버전) | 명령 팔레트 **파일 복구: 이전 버전 보기**, 또는 노트 오른쪽 클릭 → **이전 버전 보기**. 노트를 저장할 때 바뀌기 전 내용을 5분에 한 번까지, 삭제하거나 되돌리기 전에는 항상 남겨 둠(30일, 노트당 200개). 버전마다 지금 노트와 **바뀐 부분**(같은 줄은 접음) 또는 **전체 내용**을 보고, **되돌리기**(지금 내용도 버전으로 남김)·**내용 복사**·**기록 지우기**. 삭제한 노트도 목록에 남아 **되살리기** 가능(휴지통을 비운 뒤에도). 이름을 바꾸거나 옮기면 기록도 따라감. 기록은 이 컴퓨터의 앱 데이터 폴더에만 저장되고 vault에 들어가지 않아 Git 동기화로 올라가지 않음 |
| 할일 | 사이드바 **✅ 할일** — vault 전체의 `- [ ]` 할일을 지난 기한/오늘/7일 이내/나중/날짜 없음으로 묶어 보기 |
| 할일 완료 | 체크박스 클릭 → `[x]` + `✅ 오늘` (반복 할일은 다음 회차를 윗줄에 생성). Dataview 형식 줄은 `[completion:: 오늘]` |
| 반복 규칙 | `every [N] day/week/month/year`, `every weekday`, `every monday, friday`, `every 2 weeks on tuesday`, `every month on the 15th` / `on the last` / `on the 2nd tuesday`, `every year on january 5`, 뒤에 `when done` |
| 할일 편집 | 할일 줄에 마우스를 올리면 ✏ 버튼 (캘린더 시간 블록은 클릭) → 내용·우선순위·마감·예정·시작·반복·시간·알림 수정, 삭제 |
| 시간 | 할일 내용 앞에 `09:30` 또는 `09:30 - 10:00` (Day Planner 형식). 날짜가 없으면 그 데일리 노트의 날짜 |
| 알림 | `⏰ 2026-11-20 09:00` 또는 `(@2026-11-20 09:00)` (Reminder 플러그인 형식), 시간이 있는 할일은 시작 시간에 Windows 알림. 앱이 켜져 있을 때만, 설정에서 끌 수 있음 |
| Dataview 형식 | `[due:: 2026-11-20]`, `[priority:: high]`, `[repeat:: every week]` 같은 Tasks 플러그인 Dataview 필드도 읽고 그 형식 그대로 고침 |
| 할일 추가 | 할일 화면 맨 위 입력창 → 오늘 데일리 노트 끝에 `- [ ] 내용 📅 마감일` 추가 |
| 캘린더 | 사이드바 **📅 캘린더** — 월간 그리드(일요일 시작). 데일리 노트 있는 날은 점, 그날 마감/예정 할일은 칩, 완료는 ✓N |
| 날짜 상세 | 날짜 클릭 → 아래에 그날의 마감·예정·시작·완료 할일, 그 날짜 마감으로 할일 추가. **더블클릭**하면 데일리 노트 열기/만들기 |
| 외부 캘린더 | 캘린더 화면 **구독** — Google 캘린더(설정 › 캘린더 통합 › iCal 형식의 비공개 주소), Outlook, 네이버 등의 ICS/webcal 주소나 `.ics` 파일. 캘린더별 색, 월·주·일 보기에 읽기 전용으로 표시, 클릭하면 장소·메모. 반복 일정·시간대·예외 날짜 처리, 15분마다 새로 받음(⟳로 즉시), 연결이 안 되면 마지막으로 받은 일정 표시. 주소는 이 컴퓨터의 앱 설정에만 저장(vault에 안 들어감) |
| 주간 / 일간 | 캘린더 위 **월·주·일** 전환 — 종일 줄 + 시간표(시간 있는 할일을 블록으로, 겹치면 나란히), 현재 시각 선. 빈 칸 클릭하면 그 시간으로 할일 입력 시작 |
| 오늘의 노트 | 사이드바 **📝 오늘의 노트** — 없으면 데일리 노트 템플릿으로 만들어 엶 |
| 재무 | 사이드바 **💰 재무** — 월별 수입/지출/합계, 분류별 지출(클릭하면 거래 필터), 최근 6개월 추이(막대 클릭하면 그 달로), 거래 내역 |
| 재무 기록 | 재무 화면 맨 위 입력 → 오늘 데일리 노트에 `- 💸 12,000 내용 #분류` 추가 (노트에 직접 써도 됨) |
| 기록 편집 | 거래 내역 줄에 마우스를 올리면 ✏ → 종류·금액·내용·분류·날짜 수정, 삭제 (다른 태그와 목록 기호는 유지) |
| 예산 | 재무 화면 "예산 설정" — 월 전체와 분류별 예산(하위 분류 포함). 쓴 금액·남은 금액·초과, 이번 달 지난 기간 표시선. `.obsidian/rusidian.json`에 저장 |
| 거래 내역 가져오기 | 재무 화면 **내역 가져오기** — 은행·카드사·페이에서 받은 거래 내역 **CSV**(CP949/UTF-8, 쉼표·탭), **엑셀(xlsx·xls)**, **암호 걸린 엑셀**(카카오페이 다운로드 등: 비밀번호를 물어보고 파일을 여는 데만 씀, 저장 안 함), **농협 PDF**(이메일로 받은 '입출금 거래 내역', 줄바꿈된 가맹점 이름도 이어 붙임; 다른 PDF는 아직 못 읽음). 위쪽 계좌 정보 줄과 빈 열을 건너뛰고 머리글과 열(거래일자·적요·출금·입금 / 이용금액·업종 / 금액 + 입출구분 / 상태)을 추측, 대화상자에서 고칠 수 있음. '취소' 상태 줄은 건너뜀. 미리보기에서 가져올·이미 있는·건너뛸 줄을 확인한 뒤 한 노트(기본 `가져온 거래/<파일 이름>.md`)에 `📅 날짜`가 붙은 기록으로 추가. vault에 같은 날짜·종류·금액·내용이 있으면 건너뛰어 다시 가져와도 중복 없음. 휴대폰 알림으로 적힌 기록(`#자동`)은 날짜와 금액만 같아도 같은 거래로 봄 |
| 휴대폰 알림 자동 기록 | 재무 화면 **휴대폰 알림** — 안드로이드의 MacroDroid가 은행·카드·페이 알림을 파일 하나에 덧붙이고(`@@ 날짜 시각 \| 앱 \| 제목` 다음 줄에 알림 내용), Syncthing이 그 파일을 컴퓨터로 가져오면(LTE에서도, 외부 서버 저장 없음) 30초마다·창으로 돌아올 때 읽어 `가계부/YYYY-MM.md`에 `#자동` 태그가 붙은 기록으로 추가. 금액(잔액 제외)·입출금·취소·가게·보낸 사람을 읽고, 분류는 같은 가게의 이전 기록 → 잘 알려진 가게 이름 → `기타`. 내 계좌끼리 옮긴 돈(설정한 이름, 카카오페이 충전)과 광고·인증 알림은 건너뜀. 선택: ATM 인출은 연구실 비용(인건비에서 뺌), 일정 금액보다 적게 보낸 사람 돈은 식비 정산(`-금액 #식비/정산`). 처리한 알림은 컴퓨터에만 기억하고(알림 파일은 읽기만 함) 같은 날 같은 금액의 비슷한 기록이 있으면 건너뜀. 최근 알림마다 기록함·이미 있음·건너뜀·읽지 못함을 보여 줌. 설정은 이 기기 앱 설정에 저장 |
| CSV 내보내기 | 재무 화면 위 **CSV 내보내기** — 보고 있는 달의 기록을 엑셀에서 바로 열리는 CSV로 저장 |
| 거래 내역·상세 | 재무 화면 거래 내역은 날짜별로 묶여 보임. **합쳐 보기**는 결제와 그 아래 정산·환불을 한 줄(내 몫)로, **따로 보기**는 기록마다 한 줄. 줄을 누르면 상세 — 결제 금액, 정산·환불 목록(누가·언제·얼마), 돌려받은 돈 합계, 내 몫. 상세에서 각 기록 편집, **정산·환불 추가**(결제 줄 아래에 들여쓴 줄로 기록), 노트 열기 |
| 고정지출 | 재무 화면 위 **고정지출** 탭 — 매달 나가는 돈(이름·금액·날짜·찾을 글자·분류·계좌)을 등록하면 그 달 기록에서 결제를 찾아 낸 날짜·금액, D-day, "기록 없음"을 보여줌. 이번 달 낸 돈/남은 돈 합계. 두 달 이상 비슷한 날·금액으로 나간 결제는 **후보**로 보여주고 한 번에 추가, 고정지출이 아닌 후보는 **×**로 숨김(다시 보기 가능). **알림**(결제일에·하루 전·3일 전·일주일 전)을 고르면 결제일이 다가오는데 기록이 없을 때와, 결제일이 지나고 3일 안에 기록이 없을 때 Windows 알림(앱이 열려 있을 때, 15분마다 확인, 결제마다 한 번씩). 결제일 15일 전부터의 기록, 다음 달 초에 낸 기록도 낸 것으로 봄. 목록·알림·숨긴 후보는 `.obsidian/rusidian.json`에 저장 |
| 저축 | `#저축`·`#투자`(하위 분류 포함) 💸 기록은 지출이 아니라 **저축**으로 따로 셈 — 가계부 요약은 수입·지출·저축·남은 돈, 분류별 지출과 예산에서 빠짐. 저축으로 볼 분류는 자산 탭에서 바꿈(`.obsidian/rusidian.json`) |
| 자산 | 재무 화면 **자산** 탭 — 노트에 `- 🏦 2,700,000 계좌 #분류 📅 날짜`로 기록한 잔액을 계좌별로(가장 최근 기록 = 지금 잔액) 보여줌. 총자산·쓸 수 있는 돈·모으는 돈, 분류별 합계, 지난 기록 대비 변화, 계좌별 기록 내역, 총자산 변화. 탭의 **잔액 기록**으로 마지막 기록이 있는 노트(없으면 `자산.md`)에 한 줄 추가. 잔액은 설정이 아니라 노트에 있어 동기화할지 폴더로 정함 |
| 그래프 | 사이드바 **🕸 그래프** — 노트=점, `[[링크]]`=선. 휠 확대, 빈 곳 드래그 이동, 점 드래그, 마우스 올리면 이웃 강조, 클릭하면 열기 |
| 로컬 그래프 | 노트 상단 **🕸** 버튼 → 그 노트 주변(1~3단계)만. 그래프 화면의 "현재 노트 주변" 체크와 같음 |
| 그래프 색 그룹 | 그래프 화면 **색 그룹** — `path:폴더`, `tag:#태그`, `file:이름`, `-제외` 조건마다 색. 위 그룹이 먼저, 왼쪽 아래 범례. Obsidian과 같은 `.obsidian/graph.json`의 colorGroups를 읽고 씀 |

그래프는 이름 검색 강조, 고립된 노트 / 없는 노트(미해결 링크) / 첨부 파일 표시 여부를 고를 수 있습니다.
노트 800개 또는 링크 1,500개가 넘으면 배치를 화면 밖에서 먼저 계산(진행률 표시)한 뒤 그리고,
그린 장면을 캐시해 두어 이동·확대·마우스 오버가 매끄럽습니다(노트 3,000개·링크 6,000개에서 배치 약 1.8초, 이동 중 60fps 이상).

### 재무 기록 형식

노트 어디에나 목록 항목으로 씁니다. Obsidian에서도 그대로 읽히는 평범한 마크다운입니다.

```markdown
- 💸 12,000 점심 김밥 #식비                    ← 지출
- 💰 3,000,000원 월급 #급여                    ← 수입
- 💸 ₩45,000 택시 #교통/택시 📅 2026-11-10     ← 날짜 지정
- 💸 -23,000 무신사 환불 #옷                   ← 환불·돌려받은 돈 (그 분류 지출에서 뺌)
- 💰 -300,800 연구실 비용 #인건비              ← 차감 (그 분류 수입에서 뺌)
- 🏦 2,700,000 NH청년도약계좌 #저축 📅 2026-11-14 ← 계좌 잔액 (자산 탭)
- 💸 30,600 맘스터치 #식비 📅 2026-10-28
    - 💸 -10,100 김민준 정산                   ← 들여쓴 줄 = 위 결제의 정산·환불
    - 💸 -10,100 박서준 정산 📅 2026-10-29     ← 날짜가 다르면 📅
```

- 이모지(`💸` 지출 / `💰` 수입) 바로 뒤에 금액. 쉼표·`원`·`₩`·소수점 둘째 자리까지 허용. 금액 앞에 `-`(또는 `−`)를 붙이면 환불·차감으로, 같은 종류·분류의 합계에서 빠집니다.
- 첫 번째 `#태그`가 분류(`#교통/택시`처럼 계층 가능), 나머지 글자가 내용. 분류가 없으면 "미분류".
- 날짜 결정 순서: 줄의 `📅` → 데일리 노트 경로의 날짜 → 노트 속성 `date:` → 파일 이름 앞의 `YYYY-MM-DD`.
  아무것도 없으면 합계에서 빼고 "날짜를 알 수 없는 기록"으로 따로 보여줍니다.
- 기록 아래에 들여쓴 기록은 그 기록의 정산·환불입니다. 분류·날짜를 따로 적지 않으면 위 기록의 것을 씁니다.
  합계에는 각자 자기 날짜로 들어가고, 거래 내역의 "합쳐 보기"와 상세에서 결제와 함께 보입니다.
- 코드 블록 안의 줄은 무시합니다. 수정·삭제는 기록이 있는 노트에서 직접 합니다(거래 내역의 노트 이름 클릭).

### 할일 (Obsidian Tasks 플러그인 호환)

이모지 형식을 그대로 읽고 씁니다: `📅` 마감, `⏳` 예정, `🛫` 시작, `➕` 생성, `✅` 완료, `❌` 취소,
`🔁` 반복, `🔺⏫🔼🔽⏬` 우선순위, `#태그`. 상태는 `[ ]` 할일, `[/]` 진행 중, `[x]` 완료, `[-]` 취소.

- 완료 처리 시 화면에 보이던 줄과 파일의 줄이 다르면(그사이 바깥에서 수정) 아무것도 고치지 않고 거부합니다.
- 반복 규칙: `every [N|other] day|week|month|year[s]`, `every weekday`/`weekend`, `every monday, wednesday and friday`,
  `every [N] week[s] on tuesday`, `every [N] month[s] on the 15th`/`the last day`/`the 2nd tuesday`/`the last friday`,
  `every [N] year[s] on january 5th`, 그리고 각각 뒤에 `when done`. 마감(없으면 예정·시작)일 기준으로 다음 날짜를
  계산하고 다른 날짜도 같은 만큼 옮깁니다. 월말은 말일로 맞춥니다(1/31 → 2/28). 읽을 수 없는 규칙은 잘못 고치는 대신 완료를 거부합니다.
- Dataview 형식(`[due:: 2026-11-20]`, `[completion:: …]`)도 읽고, 그 형식으로 쓰인 할일은 같은 형식으로 고칩니다.

데일리 노트 위치는 `.obsidian/daily-notes.json`의 폴더·형식·템플릿 설정을 따릅니다. 날짜 형식은
Obsidian(moment.js)과 같은 규칙에 한국어 이름입니다: `YYYY YY M MM`, `MMMM`(11월), `D DD Do`(13일),
`DDD DDDD`(그해 며칠째), `dddd`(금요일) `ddd`(금), `d e E`(요일 번호), `w ww wo gggg`(일요일 시작 주),
`W WW GGGG`(ISO 주), `Q`(분기), `L`·`ll` 같은 날짜 묶음, `[문자]`와 `\문자`(글자 그대로).
이름·요일·며칠째로 된 노트 이름도 날짜로 읽어 캘린더에 연결합니다(요일이 날짜와 맞지 않으면 데일리 노트로 보지 않음).
시간(`HH`, `A` 등)처럼 날짜만으로 채울 수 없는 기호가 있으면 추측하지 않고 오류를 냅니다. 대괄호 없이 쓴
영어 단어(예: `YYYY-MM-DD - Daily`)는 Obsidian에서도 글자마다 날짜·시간 기호로 바뀌므로, 어느 단어를
`[Daily]`처럼 감싸면 되는지 알려 줍니다. 템플릿의 `{{title}}`, `{{date}}`, `{{date:형식}}`, `{{time}}`을
같은 규칙으로 채웁니다.

Obsidian 등 바깥에서 파일을 바꾸면 자동으로 트리·검색·백링크에 반영되고, 열린 노트도 다시 읽습니다.
단, 아직 저장하지 않은 편집이 있으면 덮어쓰지 않고 내 편집을 저장합니다(나중 저장이 이김).

## Git 동기화

설치된 Git으로 vault를 비공개 저장소(GitHub, GitLab, 자체 서버 등)와 맞춥니다.
중요한 서류가 있는 vault도 쓸 수 있도록 **고른 것만** 올라갑니다.

- **항상 올라가는 것:** `.obsidian` 폴더(플러그인, 테마, CSS 스니펫, 단축키, Obsidian 설정)와
  Rusidian 설정(테마·글자 크기 등, `.obsidian/rusidian-app.json`).
  기기마다 다른 `workspace.json`(열린 탭 배치)은 빼고 올립니다.
- **고른 것만 올라가는 것:** 노트 폴더. 고르지 않은 폴더, vault 맨 위의 파일, 나중에 새로 만든
  폴더는 이 컴퓨터에만 남습니다. 대화상자에서 올라갈 파일 수·크기·목록을 미리 보여 줍니다.
- **선택:** 외부 캘린더 구독 주소(비공개 주소에는 토큰이 들어 있으므로 기본은 끔).
- 50MB가 넘는 파일은 올리지 않습니다(GitHub 한도).
- 폴더 선택은 `.obsidian/rusidian.json`에 저장되어 그 vault를 쓰는 모든 기기에 같이 적용됩니다.
  원격 주소·브랜치·자동 동기화 간격은 기기마다 따로입니다.
- Git 기록은 vault 밖(앱 데이터 폴더의 `sync/`)에 두므로 vault 안에 `.git`이 생기지 않습니다.
  vault에 이미 Git 저장소가 있어도 서로 건드리지 않습니다.
- 양쪽 기기에서 같은 파일을 고쳤으면 이 기기 내용을 그대로 두고, 다른 쪽 내용을
  `이름 (충돌 2026-11-14 0305).md`로 남깁니다. 동기화가 파일을 지우거나 덮어써서 잃는 일은 없습니다.
  폴더를 목록에서 빼도 각 기기의 파일은 그대로 남고, 올리지 않는 로컬 파일과 이름이 겹치는 파일이
  내려오면 로컬 파일을 `(충돌 … 이 기기)` 이름으로 옮겨 둡니다.
- **충돌 합치기:** 동기화 알림의 **비교해서 합치기** 또는 명령 팔레트 "동기화 충돌 합치기" — vault의 충돌 사본마다
  원래 파일과 줄 단위로 비교해 같은 부분은 접고, 다른 곳마다 **원래 파일 / 사본 / 둘 다**를 고름(어느 쪽이
  이 기기·다른 기기 것인지 표시). **결과 보기·고치기**에서 합친 내용을 직접 고칠 수도 있음. **합쳐서 저장**은
  원래 파일에 쓰고(이전 버전은 파일 복구에 남음) 사본을 휴지통으로, **사본 버리기**는 원래 파일을 그대로 둠.
  글자 파일이 아니거나 원래 파일이 없으면 **사본으로 바꾸기**. 줄바꿈 방식(CRLF)과 마지막 줄바꿈은 원래 파일대로.
  `.obsidian` 안 설정 파일의 충돌 사본은 목록에 나오지 않습니다(파일 탐색기에서 직접 확인).
- 로그인은 Git이 처리합니다(Windows는 Git Credential Manager 창). Git이 없으면 대화상자에 설치 링크가 나옵니다.

### 검색 방식

`tantivy` 같은 단어 단위 색인 대신 메모리 부분 문자열 검색을 씁니다. 단어 단위 색인은
한국어에서 "회의"로 "회의록을"을 못 찾기 때문입니다(Obsidian 검색도 부분 문자열 방식).
노트 수천 개 규모에서 수 ms이고, 텍스트 사본을 따로 만들지 않습니다. 영문 대소문자는 구분하지 않습니다.

## 테스트

```bash
cargo test -p rusidian-core
```

로직은 `core`에 두고 거기서 테스트합니다. Tauri에 링크된 테스트 바이너리는 Windows에서
GUI 매니페스트가 없어 `STATUS_ENTRYPOINT_NOT_FOUND`로 실행되지 않기 때문입니다.

## Windows 빌드 참고

이 환경은 `x86_64-pc-windows-gnu`(MinGW) 툴체인을 씁니다. 그래서 `src-tauri/Cargo.toml`의
`crate-type`에서 모바일 전용 `cdylib`를 뺐습니다(GNU 링커의 DLL export 65535개 한도 초과).
링크 시 나오는 `.rsrc merge failure: multiple non-default manifests` 경고는 실행에 영향이 없습니다.
